# Block Blast — Gesture Edition

Учебный проект: простая версия игры Block Blast (Pygame) с управлением
жестами руки через веб-камеру (OpenCV + MediaPipe Hands).

## Структура проекта

```
blockblast_gesture/
├── main.py             # точка входа: игровой цикл + связка с трекером жестов
├── game.py              # логика игры Block Blast (поле, фигуры, очистка линий)
├── pieces.py             # формы и цвета фигур
├── gesture_tracker.py  # распознавание руки/жеста «щипок» в отдельном потоке
├── requirements.txt
└── README.md
```

## Как запустить в PyCharm

1. Создайте новый проект в PyCharm (или откройте эту папку как проект).
2. Скопируйте все `.py` файлы и `requirements.txt` в корень проекта.
3. Создайте виртуальное окружение, если PyCharm не сделал этого сам:
   `File → Settings → Project → Python Interpreter → Add Interpreter`.
4. Установите зависимости — откройте терминал внутри PyCharm (Alt+F12) и выполните:

   ```bash
   pip install -r requirements.txt
   ```

5. Убедитесь, что к компьютеру подключена веб-камера и никакое другое
   приложение (Zoom, Teams и т.п.) не удерживает её монопольно.
6. Запустите `main.py` (правой кнопкой → Run, либо зелёная стрелка).

   При **первом** запуске `gesture_tracker.py` сам скачает файл модели
   `hand_landmarker.task` (~7–10 МБ) с серверов Google в папку проекта —
   для этого один раз нужен интернет. Дальше модель переиспользуется
   из локального файла, интернет больше не нужен.

> **Про версию mediapipe.** Начиная с версии 1.0 Google полностью убрал
> старый API `mediapipe.solutions.hands` (тот, что часто встречается в
> старых туториалах в интернете). Этот проект уже использует актуальный
> **MediaPipe Tasks API** (`mediapipe.tasks.python.vision.HandLandmarker`),
> так что версии `mediapipe>=1.0.0` из `requirements.txt` подходят.

Откроются два окна:
- **окно игры** (Pygame) — само поле Block Blast;
- **окно отладки камеры** (OpenCV) — показывает, что видит камера, точки
  руки и текущий статус (`NO HAND` / `HAND` / `PINCH`). Его удобно
  подглядывать при настройке, а на защите можно свернуть.

## Управление

| Действие | Как сделать |
|---|---|
| Навести курсор | Держите указательный палец перед камерой, курсор (красная точка) следует за его кончиком |
| Взять фигуру | Сведите большой и указательный пальцы в щипок над фигурой в лотке снизу |
| Перетащить | Двигайте руку, не разжимая пальцы |
| Отпустить/поставить на поле | Разожмите пальцы над нужной клеткой |
| `G` | Переключить режим ЖЕСТЫ ⇄ МЫШЬ (удобно для отладки без камеры) |
| `R` | Начать игру заново |
| `Esc` | Выход |

## Правила игры

- Поле 8×8. В лотке снизу — 3 случайные фигуры.
- Фигуру можно поставить на любое свободное место, куда она помещается целиком.
- Когда все 3 фигуры из лотка использованы — выдаются новые 3.
- Заполненная целиком строка или столбец очищаются и приносят очки.
- Игра заканчивается, когда ни одну из фигур в лотке некуда поставить.

## Настройка распознавания жеста

Если щипок распознаётся слишком часто/редко, поправьте порог в `main.py`
при создании трекера:

```python
tracker = GestureTracker(cam_index=0, show_debug=True, pinch_threshold=0.055)
```

Уменьшите `pinch_threshold`, если щипок срабатывает "сам по себе" (пальцы
ещё не сомкнуты, а игра уже думает, что вы держите блок). Увеличьте —
если, наоборот, приходится сводить пальцы слишком плотно.

Параметр `smoothing` (по умолчанию `0.5`) отвечает за сглаживание
дрожания курсора: меньшее значение — более плавный, но более
«инерционный» курсор.

## Возможные проблемы

- **`Не удалось открыть камеру`** — попробуйте `cam_index=1` вместо `0`
  в `GestureTracker(...)` в `main.py`, если у вас несколько камер.
- **Курсор дёргается** — увеличьте плохое освещение в комнате или
  уменьшите `smoothing`.
- **MediaPipe не устанавливается** — убедитесь, что используете
  64-битный Python версии 3.9–3.11 (на момент написания MediaPipe не
  всегда сразу поддерживает самые новые версии Python).

## Идеи для развития проекта (для отчёта/защиты)

- Добавить жест "открытая ладонь → кулак" как свайп для паузы/рестарта.
- Распознавание двух рук — вращение фигур одной рукой, перемещение другой.
- Калибровка порога щипка под конкретного пользователя перед стартом игры.
- Вынести трекинг в отдельный процесс и общаться по сокету — если
  понадобится держать более тяжёлую модель отдельно от игрового цикла.
