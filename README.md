# CV-игры — управление жестами и глазами

Учебный проект: набор игр на Pygame, которыми управляют рукой или глазами
через веб-камеру (OpenCV + MediaPipe Tasks: HandLandmarker и FaceLandmarker).
Все игры запускаются из общего меню, где игра выбирается пальцем и щипком.

## Структура проекта

```
ArtificialIntelligenceTheory/
├── launcher.py              # общее меню: выбор игры пальцем и щипком
├── core/                    # общий код для всех игр
│   ├── gesture_tracker.py   # рука: курсор, щипок (PinchHysteresis), кадры с временем
│   ├── blink_tracker.py     # глаза: моргание и положение зрачков
│   ├── gaze_calibration.py  # калибровка взгляда (для игр со зрачками)
│   ├── camera_preview.py    # окно веб-камеры в левом нижнем углу интерфейса
│   ├── exit_gesture.py      # выход жестом «средний палец»
│   ├── one_euro.py          # фильтр One Euro для курсора руки и взгляда
│   ├── display.py           # окно на весь экран с масштабированием
│   └── *.task               # модели MediaPipe (скачиваются сами при первом запуске)
├── games/
│   ├── block_blast/         # каждая игра — отдельная папка:
│   │   ├── config.py        #   название, иконка, описание для меню
│   │   ├── icon.png         #   квадратная иконка
│   │   ├── main.py          #   точка входа: цикл игры + связка с трекером
│   │   ├── game.py          #   логика и отрисовка игры
│   │   └── pieces.py        #   (у Block Blast — ещё формы фигур)
│   ├── darts/
│   ├── splinter/
│   ├── knife_hit/
│   ├── race/
│   └── spider/
├── requirements.txt
└── README.md
```

## Как запустить

1. Откройте папку проекта в PyCharm и создайте виртуальное окружение,
   если PyCharm не сделал этого сам:
   `File → Settings → Project → Python Interpreter → Add Interpreter`.
2. Установите зависимости (терминал PyCharm — Alt+F12):

   ```bash
   pip install -r requirements.txt
   ```

3. Убедитесь, что веб-камера подключена и её не держит другое приложение
   (Zoom, Teams и т.п.).
4. Запустите **`launcher.py`** — откроется меню со всеми играми.

   | Действие | Как сделать |
   |---|---|
   | Навести курсор на игру | Указательный палец перед камерой |
   | Запустить игру | Сжать пальцы (щипок) на игре в списке и держать ~0.6 с, пока не заполнится круг |
   | Прокрутить список | Щипок **вне игр** (сбоку от списка, между строками) и движение руки вверх / вниз — список тянется за рукой и немного прокатывается по инерции |
   | Мышь / клавиатура | Клик по игре, колесо или перетаскивание / стрелки ↑ ↓ + Enter |
   | Окно камеры | `K` — спрятать / показать (в меню и в играх) |
   | Вернуться в меню | `Esc` или жест «средний палец» в игре |
   | Выход | `Esc` или жест «средний палец» в меню |

   Запуск засчитывается, только если щипок начался на игре: случайно
   «притащить» сжатые пальцы на игру и запустить её нельзя. Если щипок
   начат на игре, но рука заметно ушла вверх или вниз — это прокрутка,
   а не запуск.

**Жест «средний палец» — выход** из любой игры и из меню: покажите камере
руку с поднятым средним пальцем (указательный, безымянный и мизинец
согнуты) и подержите ~0.7 с — в центре экрана заполнится круг «Выход».
Жест работает и в играх глазами: там трекер лица дополнительно ищет руку
(в каждом третьем кадре). После возврата из игры жест в меню сработает,
только когда рука хотя бы раз опустится — чтобы меню не закрылось вслед
за игрой.

**Окно на весь экран.** Каждая игра рисует в своём разрешении, а pygame
масштабирует картинку на весь экран устройства с сохранением пропорций
(по краям могут быть чёрные полосы). Обычным окном — с переменной
окружения `CV_GAMES_WINDOWED=1`.

**Сглаживание — фильтр One Euro** (`core/one_euro.py`) вместо простого
экспоненциального: пока рука или взгляд почти неподвижны, он сглаживает
сильно (курсор не дрожит), а при быстром движении почти не сглаживает
(нет запаздывания). В синтетическом тесте с шумом камеры при тех же
«дрожаниях в покое», что у сильного EMA, курсор догоняет резкое движение
за ~30 мс вместо ~300 мс. Параметры — `min_cutoff` (меньше → меньше
дрожания в покое) и `beta` (больше → меньше запаздывания), константы
`CAM_MIN_CUTOFF` / `CAM_BETA` и `GAZE_MIN_CUTOFF` / `GAZE_BETA` в начале
`main.py` игр.

Каждую игру можно запустить и напрямую — её `games/<игра>/main.py`
(правой кнопкой → Run). Запуск работает из любой рабочей папки: `main.py`
сам добавляет корень проекта в `sys.path`, чтобы найти общий пакет `core/`.

Игра запускается отдельным процессом. На это время меню закрывает окно и
освобождает камеру: одну веб-камеру может держать только одна программа.
Если игра упала, меню покажет код ошибки, а подробности будут в консоли.

При **первом** запуске трекеры сами скачают модели MediaPipe
(`hand_landmarker.task` ~7 МБ, `face_landmarker.task` ~4 МБ) в папку
`core/`. Для этого один раз нужен интернет.

> **Про версию mediapipe.** Начиная с версии 1.0 Google полностью убрал
> старый API `mediapipe.solutions.hands` (тот, что часто встречается в
> старых туториалах в интернете). Этот проект уже использует актуальный
> **MediaPipe Tasks API** (`mediapipe.tasks.python.vision`), так что версии
> `mediapipe>=1.0.0` из `requirements.txt` подходят.

В левом нижнем углу каждой игры (и меню) — **окно веб-камеры**: что видит
камера, скелет руки или отмеченные глаза и зрачки, и статус («ЩИПОК»,
«НЕТ РУКИ», «ГЛАЗА ЗАКРЫТЫ»…). Для игр глазами картинка обрезана вокруг
лица, чтобы глаза были крупнее. Клавиша `K` прячет и показывает окно.
Игры сами не ставят важные объекты в этот угол (лоток Block Blast,
столбик ножей, колонки «Паука», занозы).

## Как добавить новую игру

Создайте папку `games/<имя>/` с тремя файлами — меню найдёт её само:

- `main.py` — точка входа с функцией `main()`. Окно — через
  `open_window(...)` из `core/display.py`, выход жестом — `ExitGesture` из
  `core/exit_gesture.py` (см. любую игру). Первые строки — как в
  остальных играх (добавить корень проекта в `sys.path`), дальше можно
  импортировать `from core.gesture_tracker import ...` и т.п. Окно камеры:
  `preview = CameraPreview(tracker, высота_окна)` и `preview.draw(screen)`
  каждый кадр (`core/camera_preview.py`); `preview_rect(высота_окна)` —
  угол, который лучше оставить свободным;
- `config.py`:

  ```python
  NAME = "Моя игра"
  ICON = "icon.png"          # квадратная иконка, путь относительно папки игры
  DESCRIPTION = "Одна-две строки о том, что делать"
  CONTROLS = "рука"          # "рука" или "глаза" — значок в списке
  ORDER = 7                  # порядок в списке меню
  ```

- `icon.png` — квадратная картинка (лучше 256×256). Без иконки строка
  получит цветной квадрат с первой буквой названия.

## Block Blast

Папка `games/block_blast/`. Поле 8×8, в лотке снизу — 3 случайные фигуры.

| Действие | Как сделать |
|---|---|
| Навести курсор | Держите указательный палец перед камерой, курсор (красная точка) следует за его кончиком |
| Взять фигуру | Сведите большой и указательный пальцы в щипок над фигурой в лотке снизу |
| Перетащить | Двигайте руку, не разжимая пальцы |
| Отпустить/поставить на поле | Разожмите пальцы над нужной клеткой |
| `G` | Переключить режим ЖЕСТЫ ⇄ МЫШЬ (удобно для отладки без камеры) |
| `R` | Начать игру заново |
| `Esc` | Выход в меню |

- Фигуру можно поставить на любое свободное место, куда она помещается целиком.
- Когда все 3 фигуры из лотка использованы — выдаются новые 3.
- Заполненная целиком строка или столбец очищаются и приносят очки.
- Игра заканчивается, когда ни одну из фигур в лотке некуда поставить.

Щипок распознаётся одинаково во всех играх — см. раздел «Настройка
щипка» ниже. Сглаживание курсора — фильтр One Euro, параметры
`min_cutoff` (по умолчанию `0.5`) и `beta` (`10`) у `GestureTracker(...)`.

## Дартс

Папка `games/darts/`. Мишень стандартная:
сектора 1–20, удвоение/утроение, 25 и BULL (50). Игра — 5 раундов по
3 дротика, побеждает рекорд по сумме очков.

Каждый дротик бросается в два шага:

| Шаг | Как сделать |
|---|---|
| 1. Прицел | Сожмите пальцы (щипок) и ведите руку — перекрестие двигается по мишени. Разожмите пальцы — точка (x, y) зафиксирована |
| 2. Бросок | Снова сожмите пальцы — дротик «в руке». Резко двиньте руку вперёд (к камере) и чуть вверх и разожмите пальцы в конце движения, как при настоящем броске |
| Перенацелиться | Держите щипок неподвижно 1.5 с в шаге 2 или нажмите `A` |
| `G` / `R` / `Esc` | Режим ЖЕСТЫ ⇄ МЫШЬ / заново / выход |

Куда попадёт дротик, решает скорость руки за последние ~0.18 с перед
разжатием пальцев:

- **сила броска** = скорость руки вверх + рост руки в кадре (рука
  приближается к камере). Шкала «Сила броска» в правой панели показывает
  её вживую, пока дротик в руке, а треугольник — силу прошлого броска.
  Зелёная зона — точное попадание по вертикали; слабее — дротик уходит
  ниже прицела, сильнее — выше; совсем слабое движение броском не считается;
- **боковое движение** руки уводит дротик влево/вправо;
- плюс небольшой случайный разброс.

В режиме мыши: зажать ЛКМ — щипок, бросок — резкий взмах мышью вверх с
отпусканием кнопки.

Щипок определяется отношением «расстояние между пальцами / размер руки»
(см. «Настройка щипка»), а не абсолютным расстоянием: иначе при броске к
камере рука «растёт» и щипок разрывался бы сам собой. Физику
броска (`IDEAL_POWER`, `FWD_WEIGHT`, `POWER_TOLERANCE` и др.) можно
подстроить под свою камеру в начале `games/darts/game.py`.

## Knife Hit

Папка `games/knife_hit/`. В центре крутится бревно, **моргание обоими
глазами бросает нож**. Нож втыкается и крутится вместе с бревном. Попал
в уже торчащий нож — проигрыш. Все ножи уровня воткнуты — бревно
раскалывается, начинается следующий уровень.

| Действие | Как сделать |
|---|---|
| Бросить нож | Моргнуть (подмигивание одним глазом не считается) |
| `Пробел` | Бросить нож с клавиатуры (отладка без камеры) |
| `R` / `Esc` | Заново / выход в меню |

Каждый уровень сложнее: больше ножей, выше скорость, заранее воткнутые
ножи-препятствия и всё более хитрое вращение — ровное → волнами →
с разворотами → рывками с остановками. Каждый 5-й уровень — **босс**
(каменное бревно, хаотичное вращение, больше ножей). Яблоки на бревне —
бонус. Параметры уровней — в функции `level_config()` в `games/knife_hit/game.py`.

При первом запуске `core/blink_tracker.py` скачает модель
`face_landmarker.task` (~4 МБ). Моргание определяется по коэффициентам
мимики `eyeBlinkLeft` / `eyeBlinkRight`, которые выдаёт FaceLandmarker.
Порог сам подстраивается под то, как выглядят открытые глаза конкретного
человека. Индикатор глаза в правом нижнем углу и отладочное окно камеры
показывают текущее значение.

Если нож бросается от случайных, непроизвольных морганий, поставьте в
`games/knife_hit/main.py` `MIN_CLOSED_TIME = 0.25`: тогда засчитываются только
нарочно долгие моргания.

## Гонка в потоке (управление зрачками)

Папка `games/race/`. Вид сверху, дорога на 4 полосы: две левые —
встречные, две правые — попутные. Машина **едет туда, куда вы смотрите**
по горизонтали, скорость растёт сама (72 → 165 км/ч).

- В потоке 6 типов машин разных размеров и скоростей: легковая, спорткар,
  внедорожник, грузовик, автобус, мотоцикл. Быстрые попутные обгоняют
  сзади, в одной полосе машины тормозят за медленной передней.
- Очки — за пройденные метры, по встречке x2. Проскочить впритирку —
  бонус «Близко!». Любое касание — авария.

Перед игрой идёт **калибровка**: по очереди смотрите на три жёлтые точки
(центр, левая полоса, правая полоса), голову держите неподвижно. Если
пересели или машину «ведёт» в сторону — `C` перекалибрует.

Положение зрачка берётся по точкам радужки FaceLandmarker (468/473)
относительно уголков глаза, среднее по двум глазам. Пока глаза закрыты
(моргание), берётся последнее значение до моргания.

| Действие | Как сделать |
|---|---|
| Рулить | Смотреть влево / вправо (маркер под дорогой показывает, куда рулит взгляд) |
| Заново после аварии | Моргнуть, `Пробел` или `R` |
| `G` | Режим ГЛАЗА → МЫШЬ → КЛАВИШИ (стрелки) — отладка без камеры |
| `C` / `Esc` | Перекалибровать / выход в меню |

Настройки в начале `games/race/main.py`: `GAZE_MIN_CUTOFF` / `GAZE_BETA` —
сглаживание взгляда фильтром One Euro, `GAZE_GAIN` — чувствительность
(больше 1 — хватает меньшего движения глаз). Лучше всего работает при
хорошем ровном освещении лица и без бликов на очках.

## Пасьянс «Паук» (управление глазами)

Папка `games/spider/`. Классический «Паук»: 104 карты, 10 колонок,
5 раздач из запаса, собрать нужно 8 последовательностей от короля до туза
одной масти. Сложность — 1, 2 или 4 масти (клавиши `1` / `2` / `4`).

| Действие | Глазами | Без камеры |
|---|---|---|
| Выбрать колонку (жёлтая рамка) | Смотреть влево / вправо | `←` `→` или навести мышь |
| Взять верхнюю группу карт колонки | Моргнуть | `Пробел` / ЛКМ |
| Положить взятые карты | Перевести взгляд на колонку и моргнуть | `Пробел` / ЛКМ |
| Отменить взятие | Моргнуть на той же колонке | то же |
| Раздача из запаса | Закрыть глаза на 1 секунду | `D` / ПКМ |
| Отменить ход / новая партия | — | `U` / `N` |

Пока карты взяты, зелёной рамкой подсвечены колонки, куда их можно
положить, а на выбранной колонке полупрозрачно видно, как они лягут.
Переносится ровно та часть группы, которая подходит (например, взяли
8-7-6, а на 7 кладётся только 6).

Моргание и долгое закрытие различаются по длительности: моргание
засчитывается, когда глаза открылись, а раздача — как только глаза
закрыты дольше `LONG_CLOSE` (1 с). Пока глаза закрыты, в центре экрана
заполняется круг «раздача».

Выбор колонки взглядом — два режима, переключение `V`:
- **ВЗГЛЯД** — выбрана колонка, на которую вы смотрите (после калибровки
  по трём точкам). Переключение с задержкой и запасом у границы колонок,
  чтобы выбор не дёргался.
- **ДЖОЙСТИК** — взгляд в сторону сдвигает выбор на одну колонку, пока
  смотрите в сторону — сдвигает дальше. Надёжнее, если зрачки на вашей
  камере отслеживаются с заметным дрожанием.

Если карты берутся от случайных морганий, поставьте в
`games/spider/main.py` `MIN_BLINK = 0.2`: тогда засчитываются только нарочные моргания.

## Занозы (симулятор, щипок = пинцет)

Папка `games/splinter/`. Крупным планом ладонь пациента с занозами:
под кожей видна тёмная часть занозы, наружу торчит кончик. Кончик
пинцета — точка между большим и указательным пальцами.

1. Подведите пинцет к торчащему кончику и сведите пальцы (щипок).
2. Не разжимая пальцев, **плавно** тяните руку **вдоль занозы** наружу.
3. Разжали пальцы раньше времени — вытянутая часть остаётся снаружи,
   можно перехватиться и тянуть дальше.

- Тянуть вкось или рывком — больно, и копится «натяжение» (шкала под
  пинцетом). На пределе заноза ломается у кожи: обломок торчит всего на
  пару пикселей, и ухватить его намного труднее. Слишком резкий рывок
  ломает хрупкую занозу сразу.
- Щипок кожи мимо занозы — тоже больно. Чем больнее, тем сильнее дрожит
  рука пациента. Боль 100% — пациент отдёргивает руку, уровень заново.
- Виды заноз: деревянная, иголка кактуса (тонкая и хрупкая, не любит
  спешки), стекло (очень больно тянуть вкось), металлическая стружка.
  С уровнями заноз больше, они короче торчат, хрупче, а рука пациента
  дрожит сильнее. На первых двух уровнях пунктиром показано направление.
- Вокруг пинцета — лупа (`L` — вкл/выкл). За уровень от 1 до 3 звёзд
  в зависимости от максимальной боли.

Щипок определяется так же, как в дартсе, — по отношению «расстояние
между пальцами / размер руки» с гистерезисом (`PinchHysteresis` в
`core/gesture_tracker.py`). `G` — режим мыши (зажатая ЛКМ = щипок), `R` —
уровень заново.

## Настройка щипка

Во всех играх и в меню щипок определяется одинаково — по отношению
**«расстояние между кончиками большого и указательного пальцев / размер
руки»** (размер руки — от запястья до основания среднего пальца):

- расстояния считаются в пикселях кадра **и с учётом глубины** (координата
  `z` у MediaPipe) — поэтому пальцы, которые стоят друг за другом по
  направлению к камере, не считаются сомкнутыми;
- отношение не зависит от того, насколько далеко рука от камеры;
- щипок — отношение от 0 до `PINCH_CLOSE_RATIO = 0.25`, разжатие — выше
  `PINCH_OPEN_RATIO = 0.28` (`core/gesture_tracker.py`; небольшой запас между
  порогами не даёт щипку «мигать» на границе). 0.25 — это примерно 2.5 см
  между точками кончиков, то есть пальцы касаются или почти касаются
  (точки стоят в середине подушечек пальцев).

Текущее отношение показано в окне камеры рядом со статусом (например,
`РУКА  0.46` или `ЩИПОК  0.12`). Чтобы подобрать пороги под свою руку и
камеру: сомкните пальцы и посмотрите число, затем чуть разведите — и
поставьте `PINCH_CLOSE_RATIO` немного выше первого, а `PINCH_OPEN_RATIO` —
между ними. Если щипок срабатывает, когда пальцы ещё не касаются, —
уменьшите оба порога; если приходится сжимать слишком сильно — увеличьте.

## Возможные проблемы

- **`Не удалось открыть камеру`** — попробуйте `cam_index=1` вместо `0`
  в `GestureTracker(...)` / `BlinkTracker(...)` в `main.py` нужной игры
  (и в `launcher.py`), если у вас несколько камер.
- **Курсор дёргается** — улучшите освещение в комнате или уменьшите
  `min_cutoff` фильтра One Euro (`CAM_MIN_CUTOFF` в `main.py` игры).
- **MediaPipe не устанавливается** — убедитесь, что используете
  64-битный Python версии 3.9–3.11 (на момент написания MediaPipe не
  всегда сразу поддерживает самые новые версии Python).
